# DailyQuest Mini App — прототип v1

Это первая фронтенд-сборка интерфейса DailyQuest для Telegram Mini App.

## Что уже работает
- адаптивный неоновый интерфейс;
- демонстрационные балансы монет и кристаллов;
- уровень, XP и прогресс-бар;
- одно локальное ежедневное испытание с ответом;
- демонстрационные кнопки разделов;
- подключение Telegram Web Apps SDK.

## Важно
Это **демо-прототип**, а не готовый публичный сервис. Балансы и прогресс пока хранятся только в памяти страницы и сбрасываются при перезагрузке. Рейтинг, магазин, рефералы, проверка Telegram-пользователя и защита экономики требуют серверной части и базы данных. Не используйте демо-баланс как реальные награды.

## Запуск
Для локальной проверки откройте `index.html` в браузере. Для запуска как Telegram Mini App файлы нужно разместить на HTTPS-хостинге, затем указать URL в настройках бота через BotFather.
